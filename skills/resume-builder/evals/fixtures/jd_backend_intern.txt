后端开发实习生（2026 届）— 交易平台

岗位职责
1. 参与交易链路核心服务的开发与维护，保障高并发场景下的系统稳定性；
2. 参与性能优化，包括慢查询治理、缓存设计、接口响应时间优化；
3. 参与分布式系统的设计与落地，熟悉消息队列、分布式锁等常见方案；
4. 与产品、前端协作完成需求交付。

任职要求
1. 2026 届本科及以上，计算机相关专业；
2. 熟悉 Java 或 Go 至少一门语言，理解并发编程；
3. 熟悉 MySQL、Redis，了解索引优化与缓存一致性方案；
4. 熟悉 Linux 开发环境，熟悉 Git；
5. 有高并发、分布式项目经验者优先；
6. 有良好的工程习惯，了解单元测试、CI/CD 者优先。
